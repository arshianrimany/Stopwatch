# ⏱️ Stopwatch

A clean, dark-themed stopwatch with lap tracking, built with vanilla HTML, CSS and JavaScript.

![Preview](preview.png)


## Features

- Start, pause and reset
- Lap tracking with the option to delete any lap
- Dark theme (colors managed with CSS variables)
- Fully responsive (desktop, tablet, mobile)
- Accurate timing using `Date.now()` instead of counting intervals

## Built with

- HTML5
- CSS3 (Flexbox, Grid, CSS variables)
- JavaScript (ES6)
- [Remix Icon](https://remixicon.com/)

## Run locally

```bash
git clone https://github.com/arshianrimany/stopwatch.git
cd stopwatch
```

Then open `index.html` in your browser. No build step needed.

## What I learned

- DOM manipulation with `createElement` and `append`
- Event delegation
- Why `setInterval` drifts, and how to fix it with the real clock
